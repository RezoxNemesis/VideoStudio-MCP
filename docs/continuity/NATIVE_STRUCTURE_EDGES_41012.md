## Shared surface

Optional paired `conditioning.structureEdges:{low,high}` accepts only strict
numeric integers1..1020 with low<high. This applies to both existing basic and
Plus providers; no action, model or inference pass was added. These are actual
Sobel-L2 magnitude thresholds after the existing native5tap binomial blur, not
RGB byte limits or automatic semantic settings. Lower thresholds can retain
faint lines and also noise. Preview the native structural image before inference.

Omission retains100/200, old request bytes/fingerprints, old feature floors and
native binary pixels. Explicit100/200 is allowed and requires4.10.12 even though
its pixels match the omitted route. The existing algorithm identity remains
`native_canny_binomial5_l2_v1`; parameters do not change its blur/gradient/NMS/
hysteresis math. The bounded queue, row cancellation checks and512px limit remain.
No threshold is adjusted automatically and no guide line is drawn or repaired.

Manual Local AI drawing > Advanced settings > Custom structure edges exposes
matching low/high fields. Off omits the property. Preview and Generate use the
same native parameter validation/preparation. Explicit values are retained in
preview/study `structureEdgeThresholds` metadata, immutable requests, their
fingerprints, frozen structure PNG identity, saved retries, AI provenance,
components and editable archives. Changing a threshold under the same request ID
rejects. Frame/source and appearance PNGs remain unchanged by this control.
Ordinary canonical/alias MCP and inline AI provenance use the matching strict
schema and4.10.12 admission; opaque legacy archive floors remain unchanged.
Live relay deployment and phone execution were not performed by this agent.
