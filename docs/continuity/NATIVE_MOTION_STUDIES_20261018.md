## Retained native authoring operation

`sketch_capabilities.motionStudies` documents `add_motion_study` under
`sketch_edit`. The worker rejects this operation before admission to APKs older
than 4.7.4. Existing queue, identity, signing and deployment behavior is unchanged.

Create a 1280×720 sketch with 120 frames at 30 FPS. Manually, open **Brush / Text
→ Motion studies**, select the cartoon or character exercise, set travel and
jump height, and create the study. This creates a new layer and uses the same
native edit dispatch, revision checks, background worker, undo and archive paths
as an agent request.

An agent must first use `app_status` on an available live connector and confirm
the actual APK/server versions. Use a new sketch or unused scene identity,
stable operation ID and current expected revision:

```json
{
  "type": "add_motion_study",
  "layerId": "layer_1",
  "sceneId": "original_exercise",
  "study": "cartoon_jump",
  "settings": {"travel": 0.18, "lift": 0.24}
}
```

The other study is `walk_to_run`. Travel is a fraction of canvas width (0..0.3).
Lift is a fraction of canvas height (0.02..0.3), used only by the cartoon. Sketch
timing is preserved: 4..8 seconds and at most 240 frames. Timing outside these
limits is rejected, never silently resampled. Existing artwork is preserved;
invalid, locked-layer or duplicate-identity edits do not partially publish.

All geometry and motion are generated by Android product code. No reference
media, tracing, generated images or workspace drawing helper is used. Cartoon
anticipation, flight, squash and recovery share an area-preserving editable
transform. The character uses the existing native articulated compiler and IK.
The first character output had detached shoulders/hips: a native skinned torso
now follows four exact attachment points. Later inspection found swing soles
below the floor despite passing hard-contact metrics: the native solver now
produces ordinary editable FK keys keeping swing soles above the same floor.
Hard-plant constraints remain present and independently checked.
