# Native codec resilience

Implement approved continuity bundle section6 for existing owner and autonomous exports. The user authorizes routine design decisions and implementation without additional confirmation. This is an architectural addition to the current render lifecycle, with shared retry coordination and a durable per-device reliability index.

Keep the exact captured composition, output size, frame rate and requested bitrate across attempts. Try default platform codecs, then conservative decoder scheduling plus AVC baseline/no B frames, then software video decoding, then software video decoding and encoding. Software routes must select actual software codecs and fail clearly when unavailable. Do not downgrade final resolution or substitute preview proxies. Audio remains encoded with AAC and decoder fallback. Mezzanine transcoding and segment checkpointing follow as separate remaining requirements.

A serialized retry controller owns each attempt and output verification. Retry only decoder/encoder initialization, format and execution failures; permission, missing source, I/O, shader, DSP, muxer and verification failures terminate explicitly. Bound attempts to four. Cancel immediately suppresses retries and all late completion/error/progress callbacks; retired attempts cannot complete a newer attempt. Each attempt releases its codecs/progress polling before the next begins. Verify real container, three decoded frame samples and the whole-file checksum on a bounded worker before reporting completion. Verification remains sampled decoding, not an assertion that every frame is decodable.

Record actual named codec failures and only verified encoder successes in a bounded SQLite index keyed by device fingerprint, codec implementation, dimensions, profile, fps and failure signature. Retain error codes and configuration metadata without source URIs. Use applicable failure counts to order codec candidates, keeping alternatives available. A bad codec is deprioritized, not permanently blacklisted. Return the attempt route, actual codec names and verification proof for owner/job diagnostics.

Review hardening: per-Format decoder wrapper records initialization failure even before any codec succeeds; keys use input dimensions, codec profile string and executing fps. Encoder wrapper uses the executing Format dimensions/fps, derives AVC level from macroblocks/rate/target bitrate, rejects candidates without the exact target bitrate, and checks resolved codec format before use. Encoder width/height keys follow the actual codec configuration, including platform portrait rotation. Owner cancellation exceptions suppress callbacks; ordinary progress/terminal persistence failures deliver explicit errors to release waiting service workers. Preserve normalized codec metadata through final service publication. Project fps is not a claim that source video timing has been converted; these retries preserve the executing composition frame rate.

Regression tests exercise codec failure followed by success, bounded exhaustion, non-codec failures, stale callbacks, cancellation before start/between attempts/during verification and durable configuration-specific statistics. Device evidence adds actual conservative/software codec renders and checks image pixels, audio, dimensions, duration and the proof/index. These prove those paths on API33; fabricated hardware failures or universal device support are not claimed.
