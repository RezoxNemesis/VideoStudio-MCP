# Native character performance

The owner authorizes autonomous native animation development. Extend the existing
editable drawing system with an original clothed, anatomically structured bust
performance, using the supplied portrait only as a quality benchmark. Preserve all
earlier work and original signing identity. No Gallery or external drawing renderer.

`add_character_animation` consumes layerId, characterId (maximum 20 characters),
settings and optional speech. Settings: view front/left/right/back/high/low;
build slender/broad; material wool/leather; detail contour/tailored;
gesture pendant/explain; armLift 0..1; headTilt -12..12; skinColor, hairColor,
coatColor (ARGB colors). Defaults: front, slender, wool, tailored, pendant, .8,
0, #FFD6A078, #FF252D3D, #FF263847. Unknown fields reject. Optional speech has the
same authored/generated/prediction contract as existing face speech. Output remains
ordinary editable paths, gradient fills, transform keys and speech cels.

Use an original tailored travelling scholar: structured collar/lapels, chest and
shoulder contours, neck planes, individually segmented fingers, elbow/wrist/cuff
attachment, pendant in the gripping fingers, layered hair and material marks.
Construct in a 1280x720 design coordinate system then map uniformly to the actual
canvas; never distort anatomy when canvas aspect changes. Preserve timing,
resolution and budgets. Support 4..8 seconds, 24..240 frames, 24/30/60 FPS. Sample
physical time so common 30/60 FPS instants agree. All geometry stays in bounds or
the operation rejects atomically. Six distinct authored 2D views are not true 3D.

Manual Character performance controls use the same operation on a new layer,
asynchronous native preview/save and existing conflict/cancellation protection.
MCP exposes strict settings, capabilities and minimum native version 4.7.8.
Audio comes from real VideoStudio Open Pipeline synthesis or owned imported audio;
Sketch export remains silent and separate editor audio retains its current scope.
