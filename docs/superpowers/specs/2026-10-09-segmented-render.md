Implement continuity bundle sections5.4/6 under the owner's standing authorization, using native implementation and bounded independent review. Media3 1.11.1 resume rejects multi-sequence compositions and speed effects; it is not usable for this compositor.

Window compositions retain track order/solo/visibility, source trim/speed, gaps, opaque background, generated plates and original effect/keyframe/title/motion clocks. An effect whose clip began before a window uses a signed origin, preserving its original duration. Never alter the owner project or substitute proxies. Window clipping uses microseconds rather than minimum100ms editor trims. The ordinary whole-composition preview/export builder remains available.

Render the full original audio composition once, separately, with the existing continuous gain/pan/DSP/speed/mixer processing. Cache only a verified audio container. This prevents restarting delay/filter/compressor state at video boundaries. Audio stage recovery may restart that audio pass; video checkpoints remain reusable. Silent timelines skip audio explicitly.

Persist a render session and verified segment rows in SQLite. Bind identity to captured project/revision/effect graph/settings, renderer version and full streaming hashes of all used original and generated media. Pin byte-identical sources into validated app-private content-addressed snapshots before rendering; later owner source edits cannot alter this session's frames. Reuse a snapshot only after its full size/SHA check; stream a replacement into a stage and verify against the captured source proof before fsync/atomic rename. Preserve original MIME hints. Insufficient local snapshot capacity fails explicitly rather than rendering mutable input under a stale identity; direct Vault-backed pinning is a later storage integration. A segment records start/end, source seek configuration, actual codec configuration/route and output size/SHA. Write into deterministic staging files; verify real media before atomic finalization and database commit. On restart revalidate stored bytes/configuration before reuse. Missing/corrupt segments rerender individually. Check STOP/cancellation while hashing, between stages, during actual render and muxing; retain verified checkpoints for a later authorized retry. No deleted originals, URI exposure or fake success.

Require compatible codec initialization data/dimensions across segments, a sync sample at each segment start and monotonically increasing timestamps. If a fallback changes configuration incompatibly, explicitly rebuild affected segments with a consistent route or fail recoverably; never append incompatible bytes. Final publication requires the existing real-container/sampled-frame/full-SHA proof.

Owner and autonomous exports use this shared engine for long timelines; existing native codec engine remains the bounded per-segment worker. Session identity is independent of a transient output filename. Serialize one writer per session and keep callbacks bound to the active generation. Final service recovery preserves current scope and immutable export graph. Cache eviction must not remove active sessions or another project's data.
