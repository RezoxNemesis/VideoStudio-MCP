# Video studio 4.3.0 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent native subsystems; root integrates public contracts and release. Owner explicitly requests autonomous execution.

**Goal:** Deliver a compatible signed upgrade with richer drawing, motion, camera, audio and caption authoring.

**Architecture:** Extend shared authoring facades and reuse native renderers. Pure helpers validate bounded geometry and timing before atomic persistence; human controls and native commands invoke the same helpers.

**Tech Stack:** Android Java/Media3/Filament/SQLite; JavaScript strict MCP contracts; existing encrypted app-key delivery.

**Spec:** [4.3.0 design](../specs/2026-10-14-studio-v430-design.md)

## Global constraints

- Version 4.3.0 / code 430; preserve package, device identity, databases and pinned original signer.
- No Gallery, private media/keys in Git, paid or unconfigured generation providers.
- Original-stroke admission and real progressive hand replay remain enforced.
- Root alone coordinates Gradle/CI and commits; independent agents do not race the shared build directory.
- New native contract fields/actions require 4.3.0; aliases receive the same version checks.

## Review focus

- Legacy/split keyframes must retain sampled motion and timing after an edit.
- Symmetry cannot bypass live drawing policy or leave half a gesture after rejection.
- Valid camera endpoints may interpolate through a degenerate basis; sample actual output frames.
- Audio pan/mono must preserve fades, seek clocks, saturation and extra channel positions.
- Caption default round-trip, text layout and preview/export must agree without accepting invalid style values.
