# Video studio 4.2.0 Implementation Plan

> **For agentic workers:** Use subagent-driven implementation for independent areas; root owns integration and release.

**Goal:** Deliver an installable broad upgrade with responsive native tools and reliable private data paths.

**Architecture:** Preserve existing transaction facades and shared preview/export composition. Independent editor, audio, sketch, 3D and relay changes converge through revision-bound contracts, original ownership and one signed build.

**Tech Stack:** Android Java/Media3/Filament/SQLite; JavaScript Cloudflare SQLite Durable Objects; Node AES-GCM transport tooling.

**Spec:** [4.2.0 design](../specs/2026-10-14-studio-v420-design.md)

## Global constraints

- Preserve package, owner identity, projects and pinned original signing certificate.
- No Gallery access; no private source media or credentials in Git.
- Keep original-strokes protection and truthful source-assisted labels.
- Native/device artistic acceptance remains separate from tests and APK verification.
- No new paid provider, hosting subscription or invented deployment credentials.

## Review focus

- Human changes during an import must survive its completion.
- A cancelled transfer cannot publish partial media or lose an accepted receipt.
- Page switches, rotation and background callbacks cannot resurrect old playback.
- Clip split/trim/speed and seeks must agree with fades in preview and export.
- Missing chunks, expiry, wrong owner or a stale generation cannot become successful imports.
