# Video studio 4.0.0

This update retains application ID `com.rezoxnemesis.videostudio.next`, the original signing identity, the device-owned MCP key and existing projects. Install the compatible APK over the current app.

The launcher name is **Video studio**. Home and Editor use a charcoal and mint theme, immediate tool search, a native studio directory and growing touch targets. Sketch Studio gives the canvas more space and groups file, brush, text, layer, cel and workspace operations in menus. Browsing menus preserves live drawing; a manual selection takes control. Layer selectors retain stable identities while live metadata changes.

In **Agent**, tap **Share app key** or **Copy app key**. The same actions are reachable through the Home connection hub. A ChatGPT coding session with GitHub write access can deliver encrypted tasks through the dedicated mailbox branch without creating another MCP connector. The existing private MCP remains available. See [the app-key workflow](VIDEO_STUDIO_APP_KEY.md).

Backup packets are immutable, authenticated, bounded and ordered. Stable command IDs retain intent and prevent duplicate effects after uncertain delivery. Accepted local commands drain immediately, independently of network polling. Native pause and privacy controls apply. Expired tasks cannot begin; already admitted native jobs preserve their actual results. Results are encrypted and paged through the existing separate metadata route, avoiding its failing native command-array store. The latest saved receipt can be authenticated and viewed in Agent settings.

The backup is independent **task delivery**, not an independent two-way hosting provider. A complete Cloudflare outage delays remote receipts; local results remain saved. Remote result plaintext is bounded to 2 MiB; larger results retain their actual execution status and explicit `resultUnavailable`/`doNotRetry` markers, with the full result encrypted locally. The ordered mailbox index holds 4096 packet IDs and rejects overflow rather than dropping tasks. Android force-stop and offline state still determine when the native service runs.

This build includes the earlier 3.9.6 source repairs: bounded gzip decoding, streamed source hashing, editable Sketch text, drawing inspection, prepared live rendering and shared crop/reframe support. It does not establish completion of every item in the earlier 71-issue audit or artistic reconstruction acceptance.

Verified before packaging: **694 Android tests in 148 suites**, **188 Node tests** and **306 smoke checks**, with no failures or skipped tests. Connection and UI reviews resolved packet overwrite, uncertain retry identity, bounded/private result transport, persistence progress, offline packet order, native expiry/recovery origin, immediate local drain, Sketch selector takeover/layer races and 48dp touch width. A production metadata-carrier check round-tripped 87089 encrypted bytes across 3 pages and authenticated the complete synthetic result.

These are source/runtime and synthetic-carrier checks. The connected phone was still 3.9.5; installation, real-device 4.0.0 execution, interactive latency and artistic output acceptance remain separate gates. The Android workflow restores the pinned original key and verifies APK package, visible label, version and certificate before publishing a build artifact. Feature-branch builds do not promote the stable main release.
